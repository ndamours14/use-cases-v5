Annotation of audiovisual (AV) materials is a powerful scholarly tool that can be used for many purposes, across many fields of study. Much like a culinary recipe book, this Use Case Recipe Book aims to provide users with an informative and inspiring list of potential uses for AV annotation, with helpful lists of “ingredients” (required elements), simple to-do steps, and example projects. This recipe book is not an exhaustive list of all possible uses for AV annotation; instead, it aims to inspire. The recipes on this website can be followed precisely, or used as a jumping-off point for your own AV projects. Browse [the list of recipes](https://ndamours14.github.io/use-cases-v5/archives/), or use the search bar above to look for a specific type of project or field of research.

If you have any questions or comments about the recipe book, or you would like to contribute your own recipes, please contact **ndamours@ualberta.ca**.
